## The Challenge

For medium-sized real estate brokerages, digital reach is critical for lead acquisition. However, off-the-shelf market alternatives (WordPress, Wix, or bloated proprietary portals) carry severe operational liabilities:

- **Poor Mobile Performance:** Sluggish responsiveness on mobile devices caused by heavy client-side JavaScript libraries and uncompressed imagery.
- **Weak Technical SEO:** Suboptimal schema markup and slow rendering hurt organic search rankings for competitive local real estate queries.
- **Costly Subscriptions:** High recurring monthly fees paired with rigid templates that limit custom lead capture funnels.

The solution delivered for **Farias Dourado Imóveis** unified an exceptional end-user browsing experience, complete data ownership, and near-zero recurring hosting overhead by leveraging self-hosted private infrastructure.

---

## Technical Architecture & Highlights

- **Server-Side Rendering (SSR) with Laravel:** Generates semantic, search-indexable HTML on the server before client dispatch, maximizing Core Web Vitals.
- **Automated Image Optimization Pipeline:** High-resolution property uploads are automatically converted to next-generation WebP formats via Sharp/GD, slashing image payloads by up to 75% without perceptible loss in visual fidelity.
- **Dedicated PostgreSQL Database:** Robust schema design with spatial indexes for geographic distance queries and compound indexes for rapid price/neighborhood filtering.
- **Homelab Self-Hosting with Zero Open Ports:** Deployed inside an unprivileged LXC container in Proxmox VE and served publicly via Cloudflare Zero-Trust Tunnels.
